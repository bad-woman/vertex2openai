单字段 compose_reply 受限解码 + 滑动尾窗防截断

                    

                    
                  

                  

                    使用固定单字段工具 compose_reply 与 mode: ANY 受限解码包裹回复正文，保持 Vertex 隐式前缀缓存命中；自动适配普通回复与预填充续写，并在真流式/假流式/非流式下透明拆包（生图与联网搜索自动旁路）。

                        预填充兼容模式
                        
                      

                      
解决 3.x / 4.x 拒绝以 assistant 轮次结尾的限制

                    

                    
                  

                  

                    内置未闭合标签思维链守卫与流式去重：

                    • 智能并入（默认）：将末尾预填充并入最后一条 user 末尾，输出侧自动拼回与去重。

                    • 保留模型轮次：保留 assistant 预填充轮次，在其后补简短 user 推动语。

                    • 最小占位：仅补占位 user 保证不报错，不拼回预填充。

                    • 关闭兼容：原样下发。
